# داشبورد انبار اسنپ — ورود و خروج تجهیزات (نسخه‌ی اپ با ورود کاربری)

یک داشبورد مدیریتی که **Google Sheets** تنها دیتابیس آن است (بدون MySQL / Firebase / MongoDB)، با **ورود با نام کاربری و رمز عبور** برای کارشناسان، و قابل **نصب به‌صورت اپ** روی موبایل و دسکتاپ (PWA).

## فایل‌ها

| فایل | نقش |
|---|---|
| `Code.gs` | بک‌اند Google Apps Script — API خواندن/نوشتن روی Google Sheets + احراز هویت |
| `index.html` | داشبورد و صفحه‌ی ورود (تک‌فایلی) |
| `manifest.json` | مشخصات نصب اپ (نام، آیکون، رنگ برند) |
| `sw.js` | سرویس‌ورکر برای نصب‌پذیر شدن و بارگذاری سریع‌تر پوسته‌ی اپ |
| `icons/` | آیکون‌های اپ (سبز اسنپ) در سایزهای مختلف |

## چه چیزی تغییر کرد نسبت به نسخه‌ی قبل؟

1. **ورود کاربری (Login):** هر کارشناس با نام کاربری و رمز عبور مخصوص خودش وارد می‌شود. هیچ‌کس بدون ورود، داشبورد را نمی‌بیند.
2. **نقش‌ها:** دو نقش تعریف شده — «مدیر» (دسترسی کامل، از جمله مدیریت لیست‌ها و کاربران) و «کارشناس» (ثبت تراکنش، مشاهده‌ی داشبورد/تاریخچه/موجودی، بدون دسترسی به تنظیمات).
3. **ثبت‌کننده:** در تاریخچه، علاوه بر «نام شخص/راننده»، ستون «ثبت‌کننده» هم اضافه شده که نام کارشناس واردشده به سیستم را نشان می‌دهد — یعنی معلوم است هر تراکنش را چه کسی وارد کرده.
4. **قابل‌نصب به‌عنوان اپ (PWA):** با اضافه‌شدن `manifest.json` و `sw.js`، کاربران می‌توانند داشبورد را از مرورگر روی موبایل یا دسکتاپ «نصب» کنند تا مثل یک اپ مستقل با آیکون سبز اسنپ روی صفحه‌ی اصلی باز شود.
5. **رنگ‌بندی برند اسنپ:** رنگ اصلی داشبورد به سبز پررنگ اسنپ (`#00C56C`) تغییر کرد و آیکون اپ هم به همین رنگ ساخته شد.

> ⚠️ **نکته‌ی مهم درباره‌ی رنگ:** چون به برندبوک داخلی و فایل‌های رسمی هویت بصری شرکت اسنپ دسترسی ندارم، از نزدیک‌ترین و شناخته‌شده‌ترین سبز اسنپ (`#00C56C`) استفاده کردم. اگر کد رنگ دقیق (HEX) را از تیم برندینگ داخلی دارید، فقط کافی است در ابتدای فایل `index.html`، در بخش `:root { --brand: ... }` مقدار را جایگزین کنید؛ کل داشبورد بر اساس همین یک متغیر رنگ‌آمیزی می‌شود.

## مراحل راه‌اندازی

### ۱) ساخت شیت و نصب Apps Script (مثل قبل)
یک Google Sheet جدید بسازید، از `Extensions → Apps Script` وارد ادیتور شوید، محتوای `Code.gs` را جایگزین کد پیش‌فرض کنید و ذخیره کنید.

### ۲) اجرای اولیه
تابع `setupSheets` را یک‌بار Run کنید و مجوزهای لازم را تأیید کنید. این‌بار **چهار شیت** ساخته می‌شود: `Transactions`، `Inventory`، `Lists` و **`Users`**. در شیت `Users` یک حساب مدیر پیش‌فرض ساخته می‌شود:

- نام کاربری: `admin`
- رمز عبور: `admin123`

**بلافاصله بعد از اولین ورود، از منوی «تنظیمات → تغییر رمز عبور من» رمز عبور admin را عوض کنید، یا یک کاربر مدیر جدید با نام خودتان بسازید و admin را حذف کنید.**

### ۳) دیپلوی به‌عنوان Web App (مثل قبل)
`Deploy → New deployment → Web app` — Execute as: **Me**، Who has access: **Anyone** — و لینک `.../exec` را کپی کنید.

> هر بار کد `Code.gs` را عوض کردید، باید `New version` بگیرید و دوباره Deploy کنید.

### ۴) هاست کردن فایل‌های اپ (لازم برای دسترسی چند کارشناس)
برای اینکه همکاران دیگر هم بتوانند از یک لینک مشترک وارد شوند، پوشه‌ی کامل شامل `index.html`، `manifest.json`، `sw.js` و `icons/` را روی یک هاست ساده و **HTTPS** آپلود کنید؛ مثلاً:

- **GitHub Pages** (رایگان): یک ریپازیتوری بسازید، فایل‌ها را آپلود کنید، از `Settings → Pages` فعالش کنید.
- یا Netlify / Vercel / هاست داخلی شرکت.

> نصب اپ (Add to Home Screen) و کارکرد صحیح `crypto.subtle` برای هش رمز عبور، به HTTPS نیاز دارد. برای تست شخصی می‌توانید فایل را مستقیم در مرورگر هم باز کنید، ولی برای استفاده‌ی تیمی حتماً هاست HTTPS بگذارید.

### ۵) اتصال و ورود
لینک را باز کنید، آدرس Web App مرحله‌ی ۳ را در پنجره‌ی «اتصال به Google Sheets» وارد کنید، سپس با `admin` / `admin123` وارد شوید.

### ۶) ساخت حساب برای کارشناسان
از تب **تنظیمات و تجهیزات → مدیریت کارشناسان و کاربران** (فقط برای نقش مدیر قابل‌مشاهده است)، برای هر کارشناس یک نام کاربری، رمز عبور اولیه، نام کامل و نقش (کارشناس/مدیر) تعریف کنید. همان لینک اپ را برایشان بفرستید تا با همین مشخصات وارد شوند.

### ۷) نصب به‌عنوان اپ روی موبایل/دسکتاپ
- **اندروید (Chrome):** روی لینک باز شده، منوی سه‌نقطه → «Add to Home screen» / «Install app».
- **iOS (Safari):** دکمه‌ی Share → «Add to Home Screen».
- **دسکتاپ (Chrome/Edge):** آیکون نصب کنار نوار آدرس، یا منو → «Install انبار اسنپ».

بعد از نصب، یک آیکون سبز اسنپ روی صفحه‌ی اصلی/دسکتاپ ظاهر می‌شود که داشبورد را تمام‌صفحه و بدون نوار آدرس مرورگر باز می‌کند.

## ساختار Google Sheets (به‌روزشده)

### شیت `Transactions`
| شناسه | تاریخ و ساعت | شهر | دسته | نوع تجهیز | رنگ | نام شخص/راننده | ثبت‌کننده (کارشناس) | نوع عملیات | تعداد | موجودی پس از ثبت |
|---|---|---|---|---|---|---|---|---|---|---|

### شیت `Inventory`
| شهر | دسته | نوع تجهیز | رنگ | موجودی فعلی |
|---|---|---|---|---|

### شیت `Lists`
| شهرها | انواع باکس | رنگ‌ها | سایر تجهیزات |
|---|---|---|---|

### شیت `Users` (جدید)
| نام کاربری | رمز عبور (هش‌شده) | نام و نام خانوادگی | نقش | فعال | تاریخ ایجاد |
|---|---|---|---|---|---|

رمز عبور هرگز به‌صورت متن ساده ذخیره نمی‌شود؛ همیشه هش SHA-256 آن (که در مرورگر خود کاربر محاسبه می‌شود) در شیت نوشته می‌شود.

## نکات امنیتی — صادقانه و مهم

این پیاده‌سازی برای **یک ابزار داخلی و کوچک** طراحی شده، نه یک سامانه‌ی امنیتی سازمانی. قبل از استفاده‌ی جدی بدانید:

- چون Web App با دسترسی **Anyone** منتشر می‌شود، هر کسی که لینک API را داشته باشد فنی می‌تواند مستقیماً (بدون رد شدن از صفحه‌ی ورود) به آن درخواست بزند. صفحه‌ی ورود، ورود از طریق داشبورد را کنترل می‌کند، اما یک لایه‌ی امنیتی سمت سرور به معنای enterprise (مثل توکن‌های منقضی‌شونده یا OAuth واقعی) نیست.
- رمزها با SHA-256 ساده هش می‌شوند (بدون salt)؛ برای امنیت بالاتر می‌توان از الگوریتم‌های استاندارد رمزهای عبور (bcrypt/argon2) در یک بک‌اند واقعی استفاده کرد که خارج از توان Google Apps Script بدون سرویس‌های جانبی است.
- اگر داده‌ی داخل انبار حساس یا محرمانه است، لینک Web App را فقط داخل شبکه‌ی شرکت به اشتراک بگذارید و دسترسی «Anyone» را با احتیاط بیشتری مدیریت کنید (یا مطابق نیاز، به سمت راهکارهای رسمی‌تر مثل Google Apps Script + Google Workspace Domain restriction مهاجرت کنید).

## امکانات کامل داشبورد

- ورود با نام کاربری/رمز عبور و دو نقش «مدیر» و «کارشناس»
- کارت‌های آماری: کل موجودی، مجموع ورود، مجموع خروج، تعداد شهرها
- نمایش موجودی هر شهر به‌صورت کارت گرافیکی + نوار پیشرفت + آیکون‌های باکس
- نمودار توزیع موجودی بر اساس نوع تجهیز و مقایسه‌ی شهرها
- فرم ثبت سریع تراکنش با پیش‌نمایش موجودی لحظه‌ای، به همراه ثبت خودکار نام کارشناس واردشده
- تعریف «سایر تجهیزات» غیر از باکس از تب تنظیمات
- تاریخچه‌ی کامل با جستجو و فیلتر بر اساس شهر، نوع عملیات، دسته و نام شخص
- جدول موجودی به تفکیک نوع و رنگ با فیلتر شهر
- مدیریت لیست شهرها / انواع باکس / رنگ‌ها / سایر تجهیزات و مدیریت کاربران (فقط مدیر)
- تغییر رمز عبور شخصی برای هر کاربر
- طراحی ریسپانسیو، راست‌به‌چپ، با رنگ‌بندی سبز اسنپ
- قابل نصب به‌عنوان اپ (PWA) روی موبایل و دسکتاپ
